# Проект создания интернет - магазина
## Данный проект предназначен для интернет - торговли

Проект представлен web-страницами с контактной информацией и каталогом продуктов

Имеются классы Category и Product, их модели.

Представлены инструменты ORM для хранения объектов классов в базе данных.


## Установка
Проект можно скачать архивом с GitHub и использовать при помощи PyCharm. *.exe пока нет
